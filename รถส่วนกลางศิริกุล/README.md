# ระบบบันทึกรถส่วนกลางศิริกุล

เว็บแอปบนมือถือ สร้างด้วย Google Apps Script ใช้ฟรี ไม่ต้องมีเซิร์ฟเวอร์

- ใน Google Drive จะมีโฟลเดอร์แยกชื่อ **รถส่วนกลางศิริกุล** (สร้างอัตโนมัติ) ข้างในมี:
  - Google Sheet "รถส่วนกลางศิริกุล - ข้อมูล"
  - โฟลเดอร์ `รูปภาพ` (แยกโฟลเดอร์ย่อยรายเดือน)
- สิทธิ์: `staff` บันทึกและดูของตัวเอง / `manager` ดูทั้งหมดและแจ้งเตือนวันหมดอายุ / `admin` เพิ่มเติมคือจัดการรถ

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | หลังบ้าน อ่าน/เขียน Sheet, อัปโหลดรูปเข้า Drive, ตรวจสิทธิ์ |
| `index.html` | หน้าเว็บสำหรับมือถือ (บีบอัดรูปก่อนอัปโหลด) |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา, สิทธิ์ที่ขอ, การเข้าถึง) |

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ด้วยบัญชี Google ของศิริกุล การบัญชี)

1. เปิด https://script.google.com แล้วกด **โปรเจกต์ใหม่** ตั้งชื่อ "รถส่วนกลางศิริกุล"
2. กดไอคอน ⚙ **การตั้งค่าโปรเจกต์** แล้วติ๊ก **แสดงไฟล์ Manifest "appsscript.json" ในเครื่องมือแก้ไข**
3. วางโค้ดจากไฟล์ในโฟลเดอร์นี้:
   - `Code.gs` วางทับในไฟล์ Code.gs ที่มีอยู่
   - `appsscript.json` วางทับไฟล์ที่เปิดขึ้นมา
   - กด **+ → HTML** ตั้งชื่อ `index` (ไม่ต้องใส่ .html) แล้ววางเนื้อหา `index.html`
4. เลือกฟังก์ชัน **setup** ในแถบด้านบน แล้วกด **เรียกใช้** อนุญาตสิทธิ์ตามที่ขอ
   (ระบบจะสร้างโฟลเดอร์ "รถส่วนกลางศิริกุล" พร้อม Sheet และโฟลเดอร์รูปภาพใน Drive ให้ ดูลิงก์ได้ที่ "บันทึกการดำเนินการ")
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคนในโดเมนของคุณ** (ถ้าใช้ Google Workspace)
6. คัดลอก URL ที่ได้ ส่งเข้ากลุ่มไลน์ แล้วให้แต่ละคนเปิดบนมือถือและเลือก "เพิ่มไปที่หน้าจอโฮม"

## เพิ่มผู้ใช้
เปิด Sheet แท็บ **ผู้ใช้** แล้วเพิ่มแถว: อีเมล, ชื่อ, สิทธิ์ (`staff`/`manager`/`admin`), ใช้งาน (`Y`)
ผู้ที่ไม่อยู่ในแท็บนี้จะเข้าไม่ได้ ปิดการใช้งานโดยเปลี่ยนเป็น `N`

## เพิ่มรถ
แอดมินเปิดแอป → แท็บ **รถ** → กรอกทะเบียนและวันหมดอายุ

## ให้ผู้จัดการเปิดดูรูปได้
ลิงก์รูปในรายการจะเปิดได้เฉพาะคนที่มีสิทธิ์ในโฟลเดอร์ "รถส่วนกลางศิริกุล"
ให้แชร์โฟลเดอร์นั้นให้ผู้จัดการ/ทีมบัญชีแบบ **ผู้ดู** (แชร์ที่โฟลเดอร์หลักครั้งเดียว ครอบคลุมทั้ง Sheet และรูป)

## แก้โค้ดภายหลัง
แก้ไฟล์ แล้ววางใน Apps Script อีกครั้ง จากนั้น **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** (URL เดิมไม่เปลี่ยน)

## ข้อจำกัด
- เปิดครั้งแรกหลังไม่มีคนใช้อาจช้า 1-3 วินาที
- ถ้าใช้ Gmail ส่วนตัว (ไม่ใช่ Workspace) ระบบอ่านอีเมลผู้ใช้ไม่ได้ ต้องใช้บัญชีองค์กรของศิริกุลเท่านั้น
- ยังไม่มีการแก้ไข/ลบรายการในแอป ให้แก้ใน Google Sheet โดยตรง
