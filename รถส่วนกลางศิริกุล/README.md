# ระบบรถส่วนกลางศิริกุล

ระบบเบิก-คืนรถส่วนกลางของ Sirikul Accounting ใช้ฟรี ไม่ต้องมีเซิร์ฟเวอร์

- **หน้าคนขับ (มือถือ)**: https://sirikulacc-tech.github.io/-sirikul/  (QR ของรถแต่ละคันชี้มาที่นี่ + `?car=รหัสรถ`)
- **หน้าแอดมิน (คอมพิวเตอร์)**: https://sirikulacc-tech.github.io/-sirikul/?admin=1

## โครงสร้าง

```
GitHub Pages (ตัวระบบ: หน้าจอ + การคำนวณทั้งหมด)
   index.html  app.css  app.js  fest.css  fest.js   ← อยู่ที่รากรีโพ
        │  ส่งคำขอแบบไม่ใช้บัญชี Google (ไม่มีปัญหามือถือที่ล็อกอินหลายบัญชี)
        ▼
Apps Script = ประตูเก็บข้อมูล            ← รถส่วนกลางศิริกุล/Code.gs
   อ่าน/เขียน Sheet, เก็บรูปลง Drive, อ่านสำเนาทะเบียน (OCR)
   กฎที่เลี่ยงไม่ได้: กันเบิกซ้อน, รหัสแอดมิน, ตรวจข้อมูลก่อนบันทึก, ไม่มีคำสั่งลบข้อมูล
        ▼
Google Sheets + Drive ของศิริกุล (ข้อมูลทั้งหมด)
```

| ไฟล์ | อยู่ที่ | หน้าที่ |
|---|---|---|
| `index.html`, `app.css`, `app.js`, `fest.css`, `fest.js` (+ `manifest.webmanifest`, `sw.js`, `icons/`) | รากรีโพ → GitHub Pages | หน้าจอคนขับและแอดมิน, คำนวณนับถอยหลัง แจ้งเตือน เลขไมล์ล่าสุด ประวัติ รายงาน, ส่งออก Excel, แยกข้อมูลสำเนาทะเบียน, ย่อรูปก่อนส่ง |
| `รถส่วนกลางศิริกุล/Code.gs` | วางใน Apps Script | ประตูเก็บข้อมูลและกฎสำคัญ |
| `รถส่วนกลางศิริกุล/appsscript.json` | วางใน Apps Script | ตั้งค่าโปรเจกต์ (เขตเวลา, สิทธิ์, Drive API สำหรับ OCR) |

## ข้อมูลเก็บที่ไหน
- **GitHub (รีโพนี้)**: เก็บเฉพาะตัวระบบ (โค้ด) ไม่มีข้อมูลการใช้งาน `.gitignore` กันไฟล์ข้อมูล (Excel, CSV, PDF, รูป) ไม่ให้ถูก commit
- **Google Drive ของศิริกุล** โฟลเดอร์ `รถส่วนกลางศิริกุล`: Sheet "รถส่วนกลางศิริกุล - ข้อมูล" (แท็บ รถ, การใช้รถ, ค่าใช้จ่าย, ซ่อมบำรุง, รายชื่อคนขับ)
  และโฟลเดอร์ `รูปภาพ`, `เอกสารรถ` (สำเนาทะเบียน), `โลโก้`
- หน้าเว็บโหลดข้อมูลการใช้รถและค่าใช้จ่าย **12 เดือนล่าสุด** มาคำนวณ รายงานย้อนหลังดึงเฉพาะเดือนที่เลือก
- เบอร์โทรคนขับไม่ถูกส่งไปหน้าคนขับ ดูได้เฉพาะหน้าแอดมิน

## ติดตั้ง / อัปเดตส่วน Apps Script
ติดตั้งครั้งแรก (ทำไปแล้วในบัญชี สำนักงาน ศิริกุลการบัญชี):
1. script.google.com → โปรเจกต์ "รถส่วนกลางศิริกุล" → วาง `Code.gs` และ `appsscript.json`
2. เรียกใช้ `setup` → อนุญาตสิทธิ์ (หน้า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด ขั้นสูง → ไปที่แอป → อนุญาต)
3. ทำให้ใช้งานได้ → เว็บแอป → เรียกใช้ในฐานะ **ฉัน**, ผู้มีสิทธิ์เข้าถึง **ทุกคน**

อัปเดตเมื่อ `Code.gs` เปลี่ยน:
- วางโค้ดใหม่ → **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ดินสอ → เวอร์ชันใหม่ → ทำให้ใช้งานได้**
- **ห้ามสร้าง "การทำให้ใช้งานได้รายการใหม่"** เพราะลิงก์ `/exec` จะเปลี่ยน (ถ้าจำเป็นต้องเปลี่ยน ให้แก้ `API_URL` บนสุดของ `app.js`)
- ไฟล์ HTML ชื่อ `index` ในโปรเจกต์ Apps Script ไม่ได้ใช้แล้ว ลบได้

อัปเดตหน้าเว็บ (`index.html`, `app.css`, `app.js`): แค่ push ขึ้น GitHub แล้ว GitHub Pages จะอัปเดตเองภายใน 1-2 นาที

## รหัสแอดมิน
ตอนนี้ยังไม่เปิดใช้ ใครรู้ลิงก์หน้าแอดมินก็เข้าได้ **ควรเปิดก่อนแจก QR** (หน้าแอดมินมีเบอร์โทรคนขับ)
1. ใน Apps Script เลือกฟังก์ชัน **enableAdminPin** → เรียกใช้
2. ดูรหัส 6 หลักใน "บันทึกการดำเนินการ" (ตั้งเอง: การตั้งค่าโปรเจกต์ → คุณสมบัติของสคริปต์ → `ADMIN_PIN`)
3. มีผลทันที ไม่ต้อง deploy ใหม่ ปิดได้ด้วย **disableAdminPin** ใส่ผิดเกิน 10 ครั้งพัก 10 นาที

## หน้าคนขับ (มือถือ)
- สแกน QR ของรถ → **หน้ารถ**: แถบบนแสดงป้ายทะเบียน (สีป้ายตามประเภทรถ), ประเภทรถ (ชื่อย่อ), นับถอยหลัง พ.ร.บ./ภาษี/ประกัน (แถวประกันมี **ชื่อบริษัทประกันอยู่บรรทัดที่สอง** กดที่ชื่อเพื่อดู **ข้อมูลกรมธรรม์** ในหน้าต่างเล็ก: ชั้น เลขกรมธรรม์ ระยะเวลา ทุนประกัน เบอร์แจ้งเหตุ และปุ่มดูไฟล์กรมธรรม์)
  **วงสีรอบป้ายทะเบียน** บอกสถานะรถ: **เขียว** = ปกติ · **เหลือง** = มีรายการใกล้ครบกำหนดภายใน 30 วัน หรือใกล้เช็คระยะ · **แดง** = มีรายการเกินกำหนดแล้ว
- **สแกน QR แล้วล็อกอยู่ที่รถคันนั้น**: ไม่มีกล่อง "เปลี่ยนรถ" ปุ่ม "หน้าแรก" และช่องเลือกทะเบียนในหน้าค่าใช้จ่าย (ใช้ทะเบียนของคันที่สแกนให้เอง)
  ลิงก์ที่ไม่มี `?car=` ยังเลือกรถได้ และถ้ารถคันนั้นถูกนำออก จะกลับเป็นโหมดเลือกรถ (ล็อกนี้ซ่อนเมนูในหน้าจอเท่านั้น ไม่ใช่ระบบสิทธิ์)
- **รถที่เบิกได้**: เฉพาะรถที่ตั้งเป็น "รถส่วนกลาง (เบิกได้)" จะแสดงในหน้าแรกและกล่องเลือกรถของคนขับ รถกรรมการและรถที่ไม่ต้องเบิก (เช่น จักรยานยนต์) จะไม่แสดง ถ้าสแกน QR ของรถเหล่านั้นจะเห็นข้อมูลรถ (การ์ดสรุปมีป้ายสถานะ "รถกรรมการ" หรือ "ไม่ต้องเบิก") แต่ **ไม่มีเมนู "เบิกรถ"** เหลือเมนูข้อมูลรถ/ประวัติการใช้งาน/ประวัติซ่อมบำรุง และ Apps Script ปฏิเสธการเบิกด้วย รถเหล่านี้ยังเก็บภาษี/พ.ร.บ./ประกัน/ประวัติไว้ตามเดิม แอดมินเห็นและมีแจ้งเตือนครบทุกคัน ส่วนคนขับเห็นแจ้งเตือนเฉพาะรถที่เบิกได้
- เมนู **ข้อมูลรถ** มีการ์ด **ประกันภัยรถยนต์** เสมอ (ถ้าแอดมินยังไม่กรอกจะขึ้นข้อความว่ายังไม่มีข้อมูล) ถ้ากรอกแล้วจะแสดง: บริษัท ชั้น เลขกรมธรรม์ ระยะเวลาคุ้มครอง ทุนประกัน ค่าเสียหายส่วนแรก และ **เบอร์แจ้งเหตุ (กดโทรได้)** พร้อมปุ่ม "ดูไฟล์กรมธรรม์" ไว้ใช้ตอนเกิดเหตุ (ไม่แสดงเบี้ยประกัน)
- การ์ดสรุปรถ: ยี่ห้อ/รุ่น, สถานะ (ว่าง/ถูกเบิกโดยใคร), เลขไมล์ล่าสุด, เช็คระยะล่าสุด
- เมนู: **เบิกรถ/คืนรถ**, **ข้อมูลรถ** (รวมปุ่มดูสำเนาทะเบียน), **ประวัติการใช้งาน** (12 เดือน), **ประวัติซ่อมบำรุง**
  แตะเมนูแล้วเปิดเป็นหน้าใหม่ แถบบนอยู่ที่เดิม **ปัดขวา** (หรือปุ่มย้อนกลับของมือถือ / "← กลับเมนูรถ") เพื่อกลับ
- เบิกรถ: ปุ่มลัดชื่อคนขับ วัตถุประสงค์ และปลายทางที่ใช้บ่อย, **เลขไมล์ก่อนออกดึงจากเลขไมล์ล่าสุดในระบบมาใส่ให้เอง** (แก้ได้ถ้าไม่ตรงกับหน้าปัด)
  **เบิกรถทำทีละขั้น** ช่องถัดไปจะขึ้นเมื่อขั้นก่อนหน้าเสร็จ: 1) เลือกหรือพิมพ์ชื่อคนขับ (ต้องเป็นชื่อที่มีในระบบ) → 2) เลขไมล์ → 3) วัตถุประสงค์ → 4) ปลายทาง รูปถ่าย และปุ่ม "เบิกรถ"
  ยังไม่เลือกชื่อ จะยังไม่เห็นช่องอื่น ขั้นที่ขึ้นแล้วไม่หายกลับ และแตะปุ่มลัดแล้วระบบเลื่อนไปช่องถัดไปให้เอง (กด Enter = ไปช่องถัดไป)
  พิมพ์ชื่อที่มีในระบบแล้วไม่ต้องกรอกอะไรเพิ่ม
  **คนขับใหม่ที่ยังไม่มีชื่อ**: พิมพ์ชื่อแล้วจะขึ้นกล่องเตือน กดปุ่ม **"+ เพิ่มชื่อของฉัน"** (หรือลิงก์ "ยังไม่มีชื่อในระบบ? เพิ่มชื่อของฉันก่อนเบิกรถ" ใต้ช่องชื่อ) เพื่อไปหน้า **เพิ่มชื่อคนขับ**
  กรอกชื่อ เบอร์โทร และวันหมดอายุใบขับขี่ (ทำครั้งเดียว) กด **"บันทึกชื่อ แล้วเบิกรถต่อ"** ระบบจะพากลับมาหน้าเบิกรถพร้อมชื่อที่กรอก เบิกรถไม่ได้จนกว่าจะเพิ่มชื่อ
  ชื่อที่มีอยู่แล้วเพิ่มซ้ำไม่ได้ (กันคนอื่นแก้เบอร์) ชื่อที่แอดมินปิดใช้งานต้องติดต่อแอดมิน
  ใบขับขี่เหลือไม่เกิน 30 วันหรือหมดอายุ ขึ้นการ์ดเตือนใหญ่พร้อมปุ่มแก้ไขวันหมดอายุ, เตือนเมื่อเลขไมล์ผิดปกติ
  **คนขับที่แอดมินปิดใช้งานจะเบิกรถไม่ได้** (ขึ้นข้อความให้ติดต่อแอดมิน) แต่คืนรถที่ค้างอยู่ได้
- คืนรถไม่ต้องกรอกชื่อ แสดงระยะทางเที่ยวนี้ทันทีที่พิมพ์เลขไมล์
- แอดมินตั้ง **ประเภทรถ** ได้ในหน้าจัดการรถ ส่วน **สีป้ายทะเบียน** ไม่มีช่องให้เลือกแล้ว ระบบตั้งให้เอง: รย.1 ขาว-ดำ · รย.2 ขาว-น้ำเงิน · รย.3 ขาว-เขียว (ถ้าไม่มีรหัส ใช้ตามประเภทรถ: เก๋ง/SUV/จักรยานยนต์ ดำ · กระบะ/บรรทุก เขียว · รถตู้ น้ำเงิน) และเปลี่ยนตามเมื่อแอดมินเลือกประเภทรถใหม่ (ป้ายแดงที่เคยตั้งไว้ไม่ถูกเปลี่ยน)
- หน้าแรกมีการ์ดรถทุกคัน แจ้งเตือนรถค้างคืนเกิน 24 ชม. และวันครบกำหนดต่างๆ, แท็บค่าใช้จ่าย (น้ำมัน ล้างรถ ทางด่วน ฯลฯ)
- ปุ่ม ปกติ/มืด และปุ่ม **เต็มจอ** มุมขวาบน
- **เต็มจอ**: เบราว์เซอร์ไม่อนุญาตให้เข้าเต็มจอเองตอนเปิดหน้า ต้องให้ผู้ใช้แตะก่อน สแกน QR แล้วจะขึ้นข้อความ "แตะหน้าจอ 1 ครั้งเพื่อเปิดเต็มจอ"
  แตะที่ไหนก็ได้ครั้งแรก (Android และคอมพิวเตอร์) ระบบจะเข้าเต็มจอ (ถ้ากดออกเองจะไม่บังคับซ้ำ) ส่วน **iPhone** เข้าเต็มจอจากเว็บไม่ได้
  หน้ารถจะมีการ์ด **"เปิดเป็นแอปเต็มจอ"** ให้ติดตั้งไว้บนหน้าจอหลัก (Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม) เปิดจากไอคอนแล้วเต็มจอทุกครั้ง
  ไฟล์ที่เกี่ยวข้อง: `manifest.webmanifest`, `sw.js`, `icons/`

## หน้าแอดมิน (คอมพิวเตอร์)

**เปิดบนมือถือด้วย QR**: ในหน้าแอดมินบนคอมพิวเตอร์ กดปุ่ม **"เปิดบนมือถือ (QR)"** ที่เมนูด้านซ้ายล่าง (หรือปุ่มในหน้าภาพรวม) จะขึ้น QR ให้สแกนด้วยกล้องมือถือ แล้วเข้าหน้าแอดมินบนมือถือได้ ถ้าเปิดรหัสแอดมินไว้ ต้องใส่ PIN บนมือถือก่อน
บนมือถือ (จอแคบ) หน้าแอดมินจะเป็น **เมนูย่อสำหรับถ่ายรูปเอกสารนำเข้าข้อมูล**: **เพิ่มรถใหม่** (ถ่ายสำเนาทะเบียน ระบบกรอกข้อมูลรถให้) · **ถ่ายสำเนาทะเบียน (รถที่มีอยู่)** · **ถ่ายกรมธรรม์ประกันภัย** (เลือกรถ แล้วกล้องเปิดทันที ระบบอ่านข้อมูลมาใส่ฟอร์ม ตรวจแล้วกดบันทึก) และรายชื่อรถให้แตะดู/แก้ไข กดปุ่ม "ใช้หน้าแอดมินแบบเต็ม" ถ้าต้องการเมนูครบ (กดกลับเมนูมือถือได้) หน้าแอดมินไม่เข้าเต็มจอเองเพื่อให้กล้อง/ตัวเลือกไฟล์ทำงาน (มีปุ่มเต็มจอให้กดเอง)

| ภาพรวม | ตัวเลขสรุป และรายการ "ต้องจัดการ" **การ์ดสรุปกดได้**: รถที่ใช้งาน → จัดการรถ · ถูกเบิกอยู่ → ค้างเบิก · ใกล้ครบกำหนด 30 วัน → จัดการรถ (กรองเฉพาะคันที่ใกล้ครบ มีปุ่มล้างตัวกรอง) · ใบขับขี่หมดอายุ → คนขับ (กรองเฉพาะที่หมดอายุ) กดทะเบียนในตาราง "รถที่ถูกเบิกอยู่" หรือรายการ "ต้องจัดการ" ที่เป็นรถ เพื่อเปิดไทม์ไลน์ของคันนั้น **อัปเดตอัตโนมัติ**: หน้าภาพรวมและหน้าค้างเบิกตรวจข้อมูลใหม่เองทุก 15 วินาทีขณะเปิดแท็บอยู่ (มีตัวบอก "อัปเดตอัตโนมัติ · ล่าสุด ...") ข้อมูลเปลี่ยนจึงโหลดใหม่ทันที ถ้าแก้ Sheet ด้วยมือจะรีเฟรชเองภายใน 5 นาที |
| จัดการรถ | การ์ดรถแถบสีตามสถานะ (เขียว/เหลือง/แดง) แสดงเลขไมล์ เช็คระยะ และวันที่เหลือของ พ.ร.บ./ภาษี/ประกัน, เพิ่ม/แก้ไข/นำออกรถ, **อ่านจากสำเนาทะเบียน** (ถ่ายรูปแล้วกรอกให้ ประเภทรถและสีป้ายตั้งให้เอง อ่านเลขไทยและแก้เลขตัวถังที่ OCR อ่านผิดได้ ต้องตรวจก่อนบันทึก), แก้ทะเบียนแล้ว QR เดิมยังใช้ได้ **การเบิกใช้** ของรถแต่ละคัน (ช่อง "การเบิกใช้" ในฟอร์มรถ): **รถส่วนกลาง (เบิกได้)** · **รถกรรมการ (ไม่เปิดให้เบิก)** · **ไม่ต้องเบิก** (เช่น จักรยานยนต์) ถ้ายังไม่ตั้งค่า ระบบถือว่าจักรยานยนต์ไม่ต้องเบิก ที่เหลือเบิกได้ **ตั้งทุกคันในครั้งเดียว**: หน้าจัดการรถ กดปุ่ม **"การเบิกใช้"** (หรือกดรายการ "ตั้งค่าการเบิกใช้ของรถ N คัน" ในหน้าภาพรวม ซึ่งขึ้นเตือนจนกว่าจะตั้งครบทุกคัน) เลือกให้รถแต่ละคันแล้วกด "บันทึกการเบิกใช้" **ควรกรอกจังหวัด** เพราะแสดงบนป้ายทะเบียนในหน้าคนขับ **ข้อมูลประกันภัยรถยนต์** ในฟอร์มรถ (ส่วน "ประกันภัยรถยนต์ (ตามใบกรมธรรม์)"): บริษัท ประเภท/ชั้น (1, 2+, 3+, 2, 3) เลขกรมธรรม์ ซ่อมห้าง/ซ่อมอู่ วันเริ่ม-สิ้นสุดคุ้มครอง (วันสิ้นสุดใช้แจ้งเตือนหมดอายุ) ทุนประกัน ค่าเสียหายส่วนแรก **เบี้ยประกันรวม (เห็นเฉพาะแอดมิน)** เบอร์แจ้งเหตุ/ตัวแทน หมายเหตุความคุ้มครองอื่นๆ และ **ไฟล์กรมธรรม์** (รูปหรือ PDF) กดถ่ายรูป/เลือกไฟล์ที่ช่อง "อ่านจากกรมธรรม์" ระบบอ่านหน้าตารางกรมธรรม์แล้วกรอกให้ (อ่านได้ทั้งเลขไทย วันที่ พ.ศ./ค.ศ.) ช่องสีเขียวคือค่าที่อ่านได้ ต้องตรวจก่อนบันทึก และเตือนถ้าทะเบียนในเอกสารไม่ตรงกับรถ **ถ้า Apps Script ยังเป็นรุ่นเก่า ฟอร์มจะขึ้นกล่องเตือนสีเหลืองว่าข้อมูลประกันที่กรอกจะไม่ถูกบันทึก ต้องวางโค้ด Code.gs ใหม่ก่อน** ไฟล์ที่ถ่ายจะถูกเก็บเป็นไฟล์กรมธรรม์ด้วย |
| QR ติดรถ | QR ทุกคัน (ชี้ไปหน้าเว็บ GitHub Pages) พร้อมโลโก้ คัดลอกลิงก์ และพิมพ์ |
| ค้างเบิก | รถที่ยังไม่คืน และยกเลิกรายการที่เบิกผิด (ต้องใส่เหตุผล) |
| ประวัติรถ | ดูย้อนหลังรายเดือนว่ารถ **ไปไหนมาบ้าง**: เลือกรถ (หรือทุกคัน) และเดือน กด ‹ › ย้อนดูได้ไม่จำกัด แสดงวัน-เวลาเบิกและคืน ผู้ใช้ ปลายทาง/วัตถุประสงค์ เลขไมล์ ระยะทาง พร้อมสรุปว่าใครใช้บ้าง ค่าใช้จ่าย และซ่อมบำรุงของเดือนนั้น ดาวน์โหลด **Excel / CSV** ของเดือนที่เลือก หรือ **ดาวน์โหลดหลายเดือน** (สูงสุด 24 เดือน) เป็น Excel ไฟล์เดียว (สรุปรายเดือน + รายการไปไหนมาบ้างทั้งช่วง + ค่าใช้จ่าย + ซ่อมบำรุง) เปิดได้จากเมนู "ประวัติรถ", ปุ่ม "ดูประวัติย้อนหลังทั้งหมด" ในหน้าภาพรวม หรือปุ่ม "ประวัติรายเดือน" ในไทม์ไลน์ของรถ (ไทม์ไลน์ดูได้ 12 เดือนล่าสุด หน้านี้ดูได้ทุกเดือน) |
| รายงานรายเดือน | สรุปต่อคัน/ต่อคนขับ ต้นทุนต่อ กม. และ **ดาวน์โหลด Excel** |
| คนขับ | **เพิ่ม / แก้ไขเบอร์โทรและวันหมดอายุใบขับขี่ / ปิด-เปิดใช้งาน** ค้นหาและกรองตามสถานะใบขับขี่ ชื่อแก้ไม่ได้ (ประวัติอ้างอิงด้วยชื่อ) คนขับที่ปิดใช้งานจะเบิกรถไม่ได้ แต่คืนรถที่ค้างอยู่ได้ และประวัติยังอยู่ครบ |
| ตั้งค่า | โลโก้บริษัท ชื่อบริษัทที่แสดง และ **ธีมเทศกาล** (ดูหัวข้อด้านล่าง) |

## ธีมเทศกาล (ดูเดิลคำว่า Sirikul Accounting + โลโก้)

แบนเนอร์ชื่อบริษัท/โลโก้ที่หน้าแรก หน้ารถ หน้าแอดมิน และหน้าใส่ PIN จะเปลี่ยนเป็นธีมเทศกาลเอง **ตามวันที่** แต่ละธีมหน้าตาไม่เหมือนกัน (ฟอนต์ สี ลายพื้น ดูเดิลต่างกัน) และมีอนุภาคเคลื่อนไหวเบาๆ ทั้งหน้า

| ธีม | ช่วงที่ขึ้นเอง |
|---|---|
| ปีใหม่ (นีออน + พลุ) | 28 ธ.ค. – 3 ม.ค. |
| คริสต์มาส (ไหมพรม + หมวกซานต้า) | 18 – 27 ธ.ค. |
| ตรุษจีน (ซองแดง + โคมแดง + 福) | 3 วันก่อน – 6 วันหลังวันตรุษ |
| วาเลนไทน์ (ซองจดหมาย + ตราประทับ) | 8 – 14 ก.พ. |
| เดือนภาษี (กระดาษบัญชี + ปากกาแดง) | 1 มี.ค. – 8 เม.ย. |
| สงกรานต์ (ปืนฉีดน้ำ + ดอกไม้) | 10 – 16 เม.ย. |
| ฮาโลวีน (เมือกเขียว + แม่มด) | 24 – 31 ต.ค. |
| ลอยกระทง (โคมลอย + กระทง) | 3 วันก่อน – 1 วันหลังวันลอยกระทง (คำนวณจากข้างขึ้นเดือน 12) |
| วันเด็ก (ลูกโป่ง + ตัวต่อ ABC) | 3 วันก่อน – เสาร์ที่ 2 ของ ม.ค. |
| เทศกาลกินเจ (ธงเหลือง 齋 + ชามผัก) | 9 วัน เริ่ม 1 ค่ำ เดือน 9 (คำนวณจากวันลอยกระทง คลาดได้ ±1 วัน) |
| วันแม่ (มาลัยมะลิ + ฟ้าอ่อน) | 5 – 12 ส.ค. |
| วันพ่อ (เหลือง + โบว์ไท + แก้ว No.1) | 28 พ.ย. – 5 ธ.ค. |

- **เลือกธีมเอง**: หน้าแอดมิน → ตั้งค่า → การ์ด "ธีมเทศกาล" กดเลือกเพื่อดูตัวอย่างทันที แล้วกด "บันทึก" (เลือก "อัตโนมัติ" = ตามวันที่ หรือ "ปิด" = ไม่ใช้ธีม) ค่าที่บันทึกใช้กับทุกเครื่อง
- **ดูตัวอย่างผ่านลิงก์**: ต่อท้าย `?theme=ชื่อธีม` (`newyear` `xmas` `cny` `valentine` `tax` `songkran` `halloween` `loy` `children` `veg` `mother` `father`) หรือ `?theme=off`
- **ปิดเอฟเฟกต์เคลื่อนไหว**: กดปุ่ม ✨ ที่มุมแบนเนอร์ (จำไว้ในเครื่องนั้น) ระบบปิดให้เองถ้าเครื่องตั้งลดการเคลื่อนไหว
- **การบันทึกธีมต้องใช้ Code.gs รุ่นใหม่** (ค่า `themeMode`) ถ้ายังเป็นรุ่นเก่า ระบบจะเตือน แต่ธีมตามวันที่ใช้ได้ตามปกติ

## ข้อควรรู้
- **รีโพเป็นสาธารณะ**: โค้ดและลิงก์ระบบหาเจอได้ แต่ข้อมูลไม่อยู่บน GitHub และกฎสำคัญอยู่ที่ Apps Script จึงเลี่ยงผ่านหน้าเว็บไม่ได้
- ชื่อคนขับเป็นสิ่งที่กรอกเอง ระบบยืนยันตัวตนไม่ได้
- ใช้บัญชี Gmail ธรรมดาได้ (ไม่ต้องมี Workspace) โควตาฟรีของ Apps Script มากกว่าการใช้รถส่วนกลางหลายเท่า
- เกณฑ์เตือน: ค้างเบิก 24 ชม., ไมล์ห่างเกิน 300 กม. (`ODO_GAP`), เที่ยวเดียวเกิน 800 กม. (`TRIP_MAX`), วันหมดอายุล่วงหน้า 30 วัน — แก้ได้ใน `app.js`
- แก้ไขข้อมูลรถและคนขับได้ในหน้าแอดมิน ส่วนรายการใช้รถ ค่าใช้จ่าย และซ่อมบำรุงยังแก้/ลบในแอปไม่ได้ ให้แก้ใน Google Sheet โดยตรง
- **คู่มือฉบับนี้มีสำเนาใน Google Drive** โฟลเดอร์ `รถส่วนกลางศิริกุล` และจะอัปเดตทุกครั้งที่วิธีใช้งานเปลี่ยน

## ลบข้อมูลตัวอย่างก่อนใช้งานจริง
ระบบไม่มีคำสั่งลบข้อมูลทางหน้าเว็บโดยตั้งใจ (กันลบผิด) จึงลบข้อมูลตัวอย่างด้วยฟังก์ชันใน Apps Script:
1. วาง `Code.gs` ล่าสุด แล้วบันทึก (ไม่ต้อง deploy ใหม่ รันฟังก์ชันจากตัวแก้ไขได้เลย)
2. เลือกฟังก์ชัน **previewSampleData** → เรียกใช้ → ดู "บันทึกการดำเนินการ" ว่าจะลบอะไรบ้าง (ยังไม่ลบ)
3. เลือกฟังก์ชัน **clearSampleData** → เรียกใช้ จะลบเฉพาะรถที่เลขตัวถังขึ้นต้น "ตัวอย่าง-" (พร้อมประวัติใช้รถ/ซ่อม/ค่าใช้จ่ายของรถเหล่านั้น) และคนขับที่ชื่อมี "(ตัวอย่าง)"
   ข้อมูลจริงที่เพิ่มเองไม่ถูกแตะ รันซ้ำได้อย่างปลอดภัย

> อัปเดตหน้าจัดการคนขับต้องวาง `Code.gs` ใหม่ใน Apps Script แล้ว **ทำให้ใช้งานได้ → จัดการ → เวอร์ชันใหม่** (มีคำสั่งใหม่ `saveDriver`, `setDriverActive`, `registerDriver`, `dataVer`, `getPolicyDoc`, `carPrivate`, `setCarModes` และคอลัมน์ `useMode` ใช้กั้นการเบิกรถที่ไม่เปิดให้เบิก) ถ้ายังไม่ได้วางโค้ดใหม่ ปุ่มจัดการคนขับและช่องเบี้ยประกันจะใช้ไม่ได้ (บันทึกข้อมูลกรมธรรม์อื่นๆ ไม่ได้ด้วย) Sheet แท็บ "รถ" จะเพิ่มคอลัมน์ข้อมูลประกันให้เองเมื่อบันทึกรถครั้งแรกหลังวางโค้ดใหม่ ไม่ต้องทำอะไรเอง และ และหน้าภาพรวมจะโหลดข้อมูลเต็มทุก 60 วินาทีแทนการตรวจเลขเวอร์ชัน
